# FIX-R5-06: vapoursynth 必须钉上限 <73，绝不能裸 >=57。
# 原因链（全部有官方/实测依据）：
#   1) R73（2025-11-24，GitHub 官方 release notes，myrsloik）：
#      "the api r3 headers are no longer distributed with the windows
#      binaries, general api r3 support for plugins remains for now"
#      "vsscript r3 api support has been completely removed since nobody
#      has used it for 3+ years"
#      -> API 3 从 R73 起进入废弃通道，R72 是最后一个完整支持 API 3 的版本。
#   2) R74 官方定位 "The big installable from pip revision"，插件目录整体
#      搬迁，官方明言 "upgrading from R73 or earlier probably will break a
#      lot of things"；R80 起 "NO PLUGINS WILL BE LOADED FROM THE PREVIOUS
#      LOCATIONS" -> 老插件自动加载路径整体失效。
#   3) 实测：.venv_r4 与 _fix_r2_20261005/venv 都被 pip 爬升到 R81 后，
#      API 3 社区插件（MVTools2/NNEDI3/MaskTools2/KNLMeansCL/focus2/ffms2）
#      全部无法加载，视频链依赖自检一次性报 22 项缺失。
#   4) 爬升机制：havsfunc==33 的 requires_dist 就是 ["VapourSynth (>=57)",
#      "vsutil"]（PyPI 官方元数据），无上限；本文件原来的 vapoursynth>=57
#      同样无上限，pip 解析时必然把 VS 连带升到最新。
# 视频链实际运行环境是 tools_r4/vs_portable/r72（Portable R72，实测
# Core R72 / API R4.1 + R3.6 双支持，API 3 插件可正常加载）。本行只是
# 防止其他 venv 在 pip install -r 时意外升级的护栏。
